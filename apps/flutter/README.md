# Conduit mobile client · Flutter

The mobile client for this repository's RealWorld platform. It uses Flutter and BLoC-based state management to consume the Conduit REST API.

## Features

- Registration and login
- Personalized and global article feeds
- Article creation, reading and comments
- Profiles, favorites and tags
- BLoC-based separation of UI and application state

## Run locally

Install Flutter, start the repository's API, then run:

```bash
flutter pub get
flutter run
```

No prebuilt APK is stored in this curated repository. Configure the API base URL for the emulator or device being used.
